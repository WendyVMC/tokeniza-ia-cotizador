# Tokeniza·IA — archivo compartible

## Cómo abrirlo

1. Descomprime `Tokeniza_IA_Cotizador_Compartible.zip`.
2. Abre `Tokeniza_IA_Cotizador_Proyectos.html` con Chrome, Edge, Safari o Firefox.
3. No requiere instalación.

## Cómo compartirlo

Puedes enviar el archivo HTML directamente o compartir el ZIP completo. Dentro de la calculadora también encontrarás el botón **Compartir calculadora**, que descarga una copia limpia sin archivos adjuntos ni el token de Banxico.

## Archivos adjuntos

La selección acepta cualquier extensión. La extracción automática de texto y estructura está disponible para:

- PDF y DOCX.
- XLS, XLSX, XLSM, XLSB y ODS.
- PPTX.
- TXT, Markdown, CSV, TSV, JSON, XML, HTML y archivos de código.
- Imágenes, audio y video se pueden visualizar o reproducir, pero requieren OCR o transcripción para aportar tokens.
- Otros formatos binarios se incorporan al inventario, pero no se les asignan tokens sin una versión textual.

## Requisitos de conexión

- La consulta del tipo de cambio requiere un Bmx-Token y conexión con la API SIE de Banco de México.
- Los lectores de PDF, Word, Excel y PowerPoint se cargan desde bibliotecas públicas; requieren conexión a internet.
- Si la consulta de Banxico es bloqueada por el navegador, captura los tipos de cambio manualmente.

## Privacidad

La calculadora procesa los archivos dentro del navegador. La función **Compartir calculadora** elimina del archivo descargado el token de Banxico y las vistas previas de archivos que se hayan cargado.
